Gapping Rule of Tokkens

In between the 
      Keyword and keyword
      identifier and identifier
      keyword and identifier
      identifier and keyword

gap(spaceor new line) is compulsory.
In between other tokens gap is optional.

TypeCasting : Conversion of one data type into another is known as typecasting
  types:
        1. Implicit (widening)  
        2. Explicit (narrowing)

Impilcit Typecasting: In this we convert smaller data to larger data type.
                      It is automatically run by compiler.

Explicit Typecasting : In this we convert larger data into smaller data type.
                       We have to do it manually.
                       It is also known as lossy conversion.
